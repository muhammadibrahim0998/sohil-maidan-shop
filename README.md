# Sohil Maidan Shop - POS Management Application

Online POS & Inventory Management System for Maidan Branch.

## Tech Stack
- **Frontend:** React, Vite, Tailwind CSS, Lucide Icons, jsPDF, ExcelJS
- **Backend:** Node.js, Express, MySQL2, Cloudinary
- **Features:**
  - Real-time POS Billing & Invoicing
  - Today Sales, Expenses & Damaged Write-offs Tracking
  - Supplier & Restock Purchase Management
  - Customer & Vendor Payment Ledgers
  - WhatsApp & PDF Bill/Statement Sharing
  - Role-based Access Control (Super Admin, Shop Admin, Cashier)
